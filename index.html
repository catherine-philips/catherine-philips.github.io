Tela — AI-Powered NL2SQL Analytics Platform

Currently building a full-stack analytics platform that converts natural-language questions into secure SQL queries and auto-generated dashboards. Backend: Built robust FastAPI endpoints, implemented disk-caching for data stores, and engineered concurrency logic allowing users to cancel long-running queries mid-execution. LLM Orchestration: Implemented a self-correcting pipeline — if the LLM generates invalid SQL, we capture the database error, feed it back to the LLM, and auto-retry, drastically improving query success rate. Schema Retrieval: Optimized how the system picks which database tables are relevant to each question — trimmed down the information sent to the AI so it wouldn't get overloaded, and made sure if a user directly named a table, it was always included. Security: Added a validation step that checks every AI-generated SQL query before it runs — blocking harmful queries and stopping users with restricted access from pulling columns they weren't allowed to see. Frontend: Built the React/TypeScript Admin Panel sidebar, a View Switcher (Admin vs. User simulation), dynamic dashboard filters wired to the backend, and Cancel/Favourite UI components.
