Professional — Built at Prodian Infotech
01
Super Search — AI Content Discovery System

Context: A leading IPL franchise needed to search 3,500+ images by player, action, mood, event, and location — without manual tagging. I was the primary client contact across 3+ feedback sessions, translating those requirements into a working product. The system has two distinct layers that work together.

Layer 1 — AI Tagging Pipeline

Two independent classifiers: a player classifier (InsightFace, fine-tuned) that tags who appears in each image across 20 player categories at 98% accuracy, and a jersey classifier (ResNet) that categorises the context — match, training, press conference. Gemini API adds semantic multi-label tags: action, mood, event, location. 1,000+ images processed in 30 minutes.

Layer 2 — Search Platform

The tagged data powers a natural language search UI. User queries are parsed by Gemini using a live DB schema and converted to parameterised MySQL queries. Supports multi-turn conversation, player alias resolution ("MSD" → "MS Dhoni"), and role-based access control across 5 user roles. Delivered to production in 10 months — 100+ daily searches by the content team.

02
CSK Business Analytics Dashboard
Problem: The franchise needed a single view across four business domains — loyalty programme performance, website & app traffic, device installs, and subscription finance.

What I designed: Integrated dual GA4 properties (web + app) with weighted-average metric blending for accurate DAU/MAU/stickiness reporting. Loyalty programme KPIs pull directly from MySQL — registrations, revenue, ROAR vs SUPER plan splits, payment gateway settlements. Device install/uninstall trends sourced from Play Store and App Store exports. 03
General-Purpose RAG Document Assistant
Problem: Users needed to query documents in plain language — without knowing which file contained what, or how to search across formats. Built end-to-end solo.

What I designed: Multi-format ingestion (PDF, Excel, CSV, PPT, TXT, images) with format-aware chunking — layout-aware PDF extraction, slide-level PPT chunking, row-batched CSV/Excel. Hybrid retrieval: vector search + BM25 with Reciprocal Rank Fusion, then cross-encoder reranking. Session-based cross-document querying with source citation so users always know where an answer came from. Switchable vector store architecture (ChromaDB locally, Qdrant in production).
